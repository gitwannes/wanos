How Blocky rules work

A rule is: trigger → cases (conditions + actions). Event triggers store a catalog UUID; the UI shows the event name.

  • One blue trigger per rule. Delete it (or drag a new one) to change type — cases stay attached.
  • Match and action options follow the device (lights, blinds, Sonos/Onkyo, etc.).
  • Use When user event / When system event (and matching Fire actions). Family “start or end” triggers are gone.
  • Use When any of when several devices or events should OR together.
  • Explorer / confirm flags live on the user event (UE form) — not on rules. Disable a rule with Rule enabled. System events (SE) are catalog-only.

Snap blocks fully into the notches. Loose blocks block Save. Select a block and use Delete (toolbar), or Delete/Backspace on desktop.
