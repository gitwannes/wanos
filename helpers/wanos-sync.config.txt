#                   everything else in StatsInclude goes to StatsDest (update/newer)
#
# Job 3 LOG PULL (Pi /var/log/wanos/wanos* --> StatsDest via rsync/SSH): [PiSsh] or [LcdPiSsh]
#   RemoteLogDir + RemoteGlob compose /var/log/wanos/wanos* (app files inside the dir — NOT /var/log/wanos*)

#   Main: StatsDest\  |  LCD: StatsDest\lcd-agent\  (never StatsDest\wanos\ or …\lcd-agent\wanos\)
# LCD mode: helpers\wanos-sync.bat test|run lcd  (source = repo\_lcd-agent\ --> LcdPiSsh)
# logcopy: after log pull, copy wanos* files from that same local dir into git docs\logs
