#   StatsInclude  = include-only file NAME patterns from Pi WanOS root
#   StatsRepoPull = subset that always overwrites into the git repo (Pi wins)
#                   everything else in StatsInclude goes to StatsDest (update/newer)
#
# Job 3 LOG PULL (Pi /var/log/wanos/wanos* --> StatsDest via rsync/SSH): [PiSsh] or [LcdPiSsh]
#   RemoteLogDir + RemoteGlob compose /var/log/wanos/wanos* (app files inside the dir — NOT /var/log/wanos*)
#   Empty LocalLogSubdir = land flat under StatsDest; otherwise StatsDest\<LocalLogSubdir>\
#   Main: StatsDest\  |  LCD: StatsDest\lcd-agent\  |  WLW: StatsDest\wlw\ (+ [WlwExtraLogFiles])
# Job 4 SESSIONLOG PULL (main Pi only): RemoteRoot/sessionlog/* --> StatsDest (flat)
#   logcopy then also copies sauna_session_*.csv + sauna_sessions.db into git docs\logs (with wanos*)
# LCD mode: helpers\wanos-sync.bat test|run|logcopy lcd  (source = repo\_lcd-agent\ --> LcdPiSsh)
# WLW mode: helpers\wanos-sync.bat test|run|logcopy wlw (source = C:\data\git\be90webserver --> WlwPiSsh)
# logcopy: always after run; also mode "logcopy" alone (pull + copy into git docs\logs)
#          test = mirror dry-run only; test pull logcopy = dry-run preview of that copy
# =============================================================================
